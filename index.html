GitHub 仓库超详细保姆级接入指南

💡 核心原理：

Spring Code 是纯前端本地运行的 IDE。它通过官方提供的 GitHub REST API 直接与你的代码仓库进行安全加密通信，无需经过任何第三方中转服务器，数据绝对私密安全。

1 获取 Personal Access Token (PAT 密钥)

  1. 在手机浏览器中打开并登录 https://github.com。
  2. 点击右上角个人头像 ➔ Settings（设置）。
  3. 在设置页面的最底部，点击左侧菜单栏的 Developer Settings（开发者设置）。
  4. 点击 Personal access tokens ➔ 选择 Tokens (classic)（强烈推荐使用经典款，兼容性最佳）。
  5. 点击 Generate new token ➔ Generate new token (classic)。
  6. Note（说明）：任意填写，如 SpringCode。
  7. Expiration（有效期）：可选择 No expiration（无期限）或 90 天。
  8. 最重要权限勾选：在 Select scopes 列表中，勾选第一个大的 repo 复选框（这会自动勾选 repo:status, repo_deployment, public_repo 等所有代码读写权限）。
  9. 滑到最底部点击绿色的 Generate token 按钮。
  10. 生成后立即复制以 ghp_ 开头的一长串密钥并粘贴到 Spring Code 的 Token 输入框（注意：GitHub 只展示一次，关掉就看不到了）。

2 项目仓库全称填写规范

仓库全称必须是严格的 拥有者/仓库名 格式，严禁带有 https://github.com/ 或 .git。

✔ 正确示例：zhangsan/my-web-project

✔ 正确示例：alibaba/vue-admin

✖ 错误示例：https://github.com/zhangsan/my-project

✖ 错误示例：my-web-project (缺少用户名)

你也可以点击本工具中的“在线拉取我加入的合作与私密仓库”，系统将自动为你一键拉出你名下的所有仓库供直接选择。

3 分支 (Branch) 确认

目前 GitHub 新建仓库默认主分支多为 main，较老仓库可能为 master。请确认与你的 GitHub 仓库主分支名保持完全一致。

4 常见报错与快速排查自愈手册

1. 报 401 Unauthorized：

说明 Token 输错或已过期失效，请重新生成 Classic Token (ghp_) 复制填入。

2. 报 404 Not Found：

① 检查仓库名称是否写错；② 仓库如果不是空仓库请先在 GitHub 建立初始化 README；③ 你的 Token 缺少 repo 权限导致私有仓库无权读取。

3. 报 403 Resource not accessible by personal access token：

使用了细粒度 Token (Fine-grained) 却没有开启 Contents 的 Read and write 权限。请直接换用 Classic Token 即可秒解决！
