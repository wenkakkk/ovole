# Spring Code 移动端轻量智能 IDE

Spring Code 是专为移动端打造的轻量级、全栈 AI 编程工作台与 Git 版本协同环境。支持在手机或平板上直接连接 GitHub 仓库或导入本地项目，借助大语言模型实现局部精准修改、多版本时间轴回退与一键直推 Git 仓库。

---

## 核心特性

- **双轨工程模式**：
  - **Git 远程仓库**：一键拉取私有/合作仓库目录树，秒级获取代码并同步状态。
  - **本地工作区**：支持将本地文件夹或任意文件直接导入侧边栏，与 Git 仓库独立隔离运行。
- **右侧侧边栏版本树（时光机回退）**：
  - 导入或修改的文件自动建立历史版本快照。
  - 支持单文件任意历史节点的**一键回退**，回退后即刻刷新聊天与修改上下文。
  - 支持直接在侧边栏一键**下载最新修改后的代码**。
- **一键手动推送与自动推送**：
  - 本地导入或修改的文件，均支持点击底部**一键手动推送**直接同步新建或提交至 GitHub 目标仓库分支。
  - 支持开启**自动推送模式**，AI 生成补丁后自动核对 SHA 并提交 commit。
- **永久留存的修改与推送流水线**：
  - 代码局部替换前后详情、修改成功/失败、推送 Commit SHA 等状态永久储存在当前会话中。
  - 无论刷新网页还是切换不同会话，历史推送记录永不丢失，方便随时回溯与排查。
- **精准局部补丁算法**：
  - 基于 `SEARCH / REPLACE` 结构，支持精准定位行、去空白容错、模糊倒序匹配及首尾锚点匹配，无需全量重写大文件，避免手机端卡顿。
- **纯本地数据安全**：
  - API Key、GitHub Token、本地会话数据全部存储于本地 IndexedDB，数据不经过第三方中转服务器。

## 快速上手

### 1. 配置接口与仓库
1. 点击侧边栏底部的 **设置**。
2. 在 **接口与模型** 中填入 API Base URL 与 Key，点击“拉取与添加模型库”。
3. 在 **仓库配置** 中填入 GitHub Personal Access Token 与目标仓库全称（如 `owner/repo`）。

### 2. 本地导入与手动推送
1. 在侧边栏“项目”栏目下切换至 **本地工作区**。
2. 点击 **导入本地文件/项目**，选择手机上的文件或文件夹。
3. 打开右侧侧边栏，即可查看到已导入的文件及版本时间轴。
4. 点击右侧抽屉底部的 **一键手动推送全部最新文件**，即可直接在远端 Git 仓库创建或更新该文件！
