# Spring Code 移动端轻量智能 IDE

Spring Code 是专为移动端打造的轻量级、全栈 AI 编程工作台与 Git 版本协同环境。支持在手机或平板上直接连接 GitHub 仓库或导入本地项目，借助大语言模型实现局部精准修改、多版本时间轴回退与一键直推 Git 仓库。

---

## 核心特性

- **接口与仓库同屏合一中心**：
  - AI 接口配置与 GitHub 仓库配置整合在同一页面，一目了然，免除来回切换。
  - 内置**超详细保姆级 GitHub 接入指南**，手把手指导 Classic Token 权限勾选、仓库格式与 401/403/404/409 报错秒级排查。
- **高阶推理超参数微调**：
  - **温度 (Temperature)**：0.0 ~ 2.0 自由调节（严谨编程至创意发散）。
  - **读取上下文消息限制**：4 ~ 50 条按需限制，杜绝历史对话产生巨额无意义 Token 消耗。
  - **最大 Token 数 (Max Tokens)**：支持自由填写最大生成限额，留空自动兜底最大（16384）。
  - **一键重置**：一键将超参数恢复至官方最佳推荐配置。
- **高可视自定义 CSS 编辑器**：
  - 大幅扩充自定义全局界面 CSS 输入框高度，支持代码高亮排版与随心注入。
- **双轨工程模式**：
  - **Git 远程仓库**：一键拉取私有/合作仓库目录树，秒级获取代码并同步状态。
  - **本地工作区**：支持将本地文件夹或任意文件直接导入侧边栏，与 Git 仓库独立隔离运行。
- **右侧侧边栏版本树（时光机回退）**：
  - 导入或修改的文件自动建立历史版本快照。
  - 支持单文件任意历史节点的**一键回退**，回退后即刻刷新聊天与修改上下文。
  - 支持直接在侧边栏一键**下载最新修改后的代码**。
- **一键手动推送与自动推送**：
  - 本地导入或修改的文件，均支持点击底部**一键手动推送**直接同步新建或提交至 GitHub 目标仓库分支。
  - 支持开启**自动推送模式**，AI 生成补丁后自动核对 SHA 并提交 commit。
- **永久留存的修改与推送流水线**：
  - 代码局部替换前后详情、修改成功/失败、推送 Commit SHA 等状态永久储存在当前会话中。
  - 无论刷新网页还是切换不同会话，历史推送记录永不丢失，方便随时回溯与排查。

## 快速上手

### 1. 配置接口与仓库
1. 点击侧边栏底部的 **设置**。
2. 在 **接口与仓库** 页面中填入 API Base URL 与 Key，点击“拉取与添加模型库”。
3. 在下方紧邻的 **GitHub 账号与仓库方案** 中填入 Token 与仓库全称（若有疑问可直接点击右上角“保姆级接入教程”查看指导）。
4. 在输入框左上角点击“选择模型”，可自由滑动调节温度、上下文限制或填写最大 Token。

### 2. 本地导入与手动推送
1. 在侧边栏“项目”栏目下切换至 **本地工作区**。
2. 点击 **导入本地文件/项目**，选择手机上的文件或文件夹。
3. 打开右侧侧边栏，即可查看到已导入的文件及版本时间轴。
4. 点击右侧抽屉底部的 **一键手动推送全部最新文件**，即可直接在远端 Git 仓库创建或更新该文件！
